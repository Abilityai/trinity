## Highlights

1.0 put an agent in a seat on the team. 1.0.5 makes the seat workable day to day: projects
people and agents run work from, agents that wake when the thing they were waiting for
happens, a memory that can be searched, and an install that is closed to the network until
an admin opens it.

- **Projects are a working environment.** A project has a board view, tasks with subtasks,
  waits-on and an editable title, objective and definition of done, a Runs tab listing the
  executions behind it with cost and queue age, and context an agent reads (a written or
  uploaded brief). A task's run starts from the project. A steward agent is picked at
  creation, proposes members and task owners for one approval, and works in a per-project
  mode — Track, Propose or Auto — that the platform enforces. An existing GitHub epic can be
  imported as a project, and a task can point at its issue or pull request (ent#957,
  ent#1232, ent#1133, ent#1105, ent#1193, ent#1195, ent#1169, ent#980, ent#1235, ent#1236,
  ent#1163, ent#1240, ent#867).
- **Agents wake on their own.** An agent is woken when an ask it raised is answered, and a
  caller is woken when the run it delegated ends or asks — both on by default, with a missed
  wake delivered on the next start and a per-hour budget on caller wakes. Platform-started
  turns run on the agent's configured model (ent#790, ent#1108, ent#1102, #4357, #4536,
  #4442).
- **Asks reach someone who can answer.** An ask goes to a person who can open the agent, an
  ask raised in a room comes back to that room, an agent on a project can address the
  project's people, a changed primary re-addresses what is pending, and a refusal names who
  a card is waiting for (ent#1135, ent#1134, ent#1095, ent#1096, ent#1042, ent#1053, #4501,
  #4579).
- **Retrieval memory (default off).** Turns are captured, recalled into the prompt and
  searchable by the owner and by the agent over MCP (`search_memory`). Agent-written memory
  about a person passes anti-poisoning gates, and the owner sees a person's memory history
  with undo (ent#1022, ent#1027, ent#1028, ent#419, ent#962).
- **Voice.** A Direct call sends every spoken turn to the agent and plays its own reply,
  with stop by voice or by hand; `send_voice_reply` can address a person by role or email so
  a scheduled run can speak (ent#1046, ent#1087 in part, ent#700).
- **Systems reconcile.** `apply_system` reconciles a live instance to its manifest instead
  of suffixing `_2`, and a manifest states the whole target: skill assignments, admin
  grants, the approval map, role ids and catalog-only members (ent#695, ent#1030, ent#991,
  #4128–#4132, #4151).
- **Closed by default on the network.** External MCP access is off on a fresh install and
  switched on in Settings, agent SSH ports publish on loopback, hosted installs trust only
  their own proxies for the client address, and `DO_NOT_TRACK` is one switch after which the
  instance contacts no vendor host. Agent runtimes stop sending usage fingerprints to their
  vendors by default (ent#1101, ent#1168, ent#873, #3047, #4499, ent#986, ent#1093).
- **Access tiers tightened.** Execution reads and agent control verbs moved off the
  accessor tier, the accessor tier is no longer the default for agent routes, a suspended
  account is refused at every door and loses its live connections, and peer skill grants are
  enforced inside the container (ent#875, ent#926, ent#1258, ent#863, ent#925).
- **Operating an install.** `trinity update` is one command with preflight, published-URL
  verification and rollback; the admin password can be changed in the app; every compose
  file runs a bundled PostgreSQL; an alert names the running agents still on an old base
  image (#3007, #3825, #4175 in part, #4479, #4483).
- **Funding an agent with a card.** An operator enrolls a card and creates a mandate for an
  agent from the Payments tab, backed by Nevermined widget sessions and per-agent delegation
  binding (ent#966, ent#967; ent#965 stays open for step 3).
- **Instance-to-instance.** Cross-instance A2A signs in with AAuth agent identity, and a
  credential ask can name an agent on another Trinity as its destination (ent#862, ent#1109,
  ent#1158).

## ⚠️ Behavior changes / upgrade notes

### Move off SQLite before you upgrade

Every compose file now runs a bundled PostgreSQL (#4175). An install with data in
`trinity.db` **does not boot** on 1.0.5 until it moves: follow
[SQLITE_TO_POSTGRES.md](../migrations/SQLITE_TO_POSTGRES.md). SQLite reached end-of-support
on 2026-09-01. To stay on it for this release only, set `DATABASE_URL=` (empty) **and**
`TRINITY_ALLOW_SQLITE=1`; the override is time-boxed to 1.0.5.

### Use `trinity update`

`scripts/deploy/update.sh` (also `trinity update`) is the single entry point for updating a
self-hosted install (#3007): it runs a preflight before anything is touched, verifies the
published URL answers and rolls back if it does not.

### Rebuild the agent base image and recreate agents

The base image moves from Node.js 20 to 24 (#3886) and carries the agent-side fixes in this
release (peer skill grants in-container, runtime privacy defaults, the Gemini process group
and timeouts). Agents on the old image keep running without them; a platform alert names
which running agents are still on the old image (#4483).

### Behaviour that changes by default

- **Agent SSH ports publish on `127.0.0.1`** (ent#1168). Applied when an agent is created
  or recreated; an existing agent keeps its binding until then. Set `AGENT_SSH_BIND_ADDRESS`
  to a VPN interface address, or `0.0.0.0` for the old behaviour.
- **External MCP access is off on a fresh install** (ent#1101). An existing install keeps
  publishing `:8080` on every interface until `MCP_BIND_ADDRESS` is set. Off-box clients are
  refused until an admin turns External MCP access on under Settings → MCP Keys.
- **Chat-shared people no longer read other people's executions or use agent control
  verbs** (ent#875, ent#926). The accessor tier is no longer the default for agent routes.
- **The default turn limit is 200**, up from 50 (ent#471).
- **Agents wake on an answered ask and on a delegated run ending** (ent#790, ent#1108,
  ent#1102). Caller wakes are capped at 120 per hour per agent (`CALLER_WAKE_MAX_PER_HOUR`).
- **Terms of use are shown once** to every first-time person on any door (ent#1107). The
  shipped default is admin-editable.
- **Agent runtimes send less to their vendors.** Gemini usage statistics are off and Claude
  Code runs with `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` (ent#986, ent#1093).
- **`ANTHROPIC_BASE_URL` in an agent's `.env` is protected** (ent#1001).
- **Prod and hosted compose add an ingress network** on `172.30.0.0/24` (ent#873). The
  backend takes the client address only from the bundled nginx and Cloudflare Tunnel there.
  If that range is in use on the host, set `TRINITY_PROXY_PREFIX`.
- **A seeded default skill source that no admin retargeted follows the bundled pin** on
  upgrade (ent#529).
- **The agent Sharing tab is named Channels** (ent#225), and Credentials is its own Settings
  pane (ent#951).
- **Re-login** after the backend restarts and **reconnect** MCP clients. Keyed MCP clients
  now survive an MCP server restart (#4060).

### Config keys whose behaviour changed

Every `.env` / `docker-compose*.yml` key whose meaning changed between v1.0.0 and v1.0.5:

- `DATABASE_URL` (all compose files) — **unset now means the bundled PostgreSQL everywhere**; in 1.0.0 that was true of hosted compose only, and prod and dev fell back to SQLite. Set-but-empty selects SQLite, which the images now refuse unless `TRINITY_ALLOW_SQLITE=1`.
- `POSTGRES_PASSWORD` — **required by every compose file** (none renders without it; `start.sh` generates it). Previously required by hosted compose only.
- `POSTGRES_DB`, `POSTGRES_USER` — honoured by dev compose only; prod and hosted fix both at `trinity`.
- `DB_POOL_SIZE`, `DB_MAX_OVERFLOW` — unchanged values, but they now apply to every install, since PostgreSQL is the default.
- `DO_NOT_TRACK` — **widened**. Any value other than unset or `0` now also turns off telemetry sharing, the help widget's Bug / Feature / Feedback report, the Ask tab and the `ask_trinity` MCP tool, and removes both vendor hosts from the Content-Security-Policy. Previously it disabled the operator-intake POST only (#4499).
- `VOICE_MODEL` — default moves `models/gemini-3.1-flash-live-preview` → `models/gemini-3.8-live`; the old model stops working on 2026-11-17 (#4440).
- `FRONTEND_URL` — invite emails now take their sign-in link **from this key only**. Empty, the email carries no link; previously the link was derived from request headers and could point at the public chat host (ent#1255). Set it whenever `PUBLIC_CHAT_URL` is set.
- `CANARY_ENABLED` — `true` / `yes` / `on` now enable it as `1` does; an unrecognised value leaves it off and logs a warning (#1988).
- `VITE_BUG_REPORTING_ENABLED` — build-time only: it applies where the frontend is built on the machine. To switch reporting off on the published images use the run-time `BUG_REPORTING_ENABLED=false` (#4499).
- `ASK_TRINITY_ENDPOINT` — pointing it at an unreachable URL is no longer the way to switch the tool off; `ASK_TRINITY_ENABLED=false` unregisters it (#4499).
- `INTERNAL_API_SECRET` — also signs MCP session ids, so rotating it costs every connected MCP client one reconnect (#4060).
- `FRONTEND_PORT` — unchanged meaning, now combined with `FRONTEND_BIND_ADDRESS` in prod and hosted compose.

New keys (no prior meaning): `TRINITY_ALLOW_SQLITE`, `TRINITY_POSTGRES_VOLUME`,
`MCP_BIND_ADDRESS`, `MCP_EXTERNAL_ACCESS`, `AGENT_SSH_BIND_ADDRESS`, `FRONTEND_BIND_ADDRESS`,
`CADDY_PROXY_PORT`, `TRINITY_PROXY_PREFIX`, `TRUSTED_PROXIES`, `BUG_REPORTING_ENABLED`,
`ASK_TRINITY_ENABLED`, `ALLOW_PDF_UPLOADS`, `DIRECT_VOICE_ENABLED`, `GEMINI_STT_MODEL`,
`GEMINI_TTS_MODELS`, `CALLER_WAKE_MAX_PER_HOUR`, `NEVERMINED_DELEGATION_MAX_INFLIGHT`,
`TRINITY_MEMORY_EMBEDDING_MODEL`, `FASTEMBED_CACHE_PATH` (the last two are image-internal).
`system_settings` keys were not swept mechanically this release.

## Known limitations

- **SQLite is refused by default**, and the `TRINITY_ALLOW_SQLITE=1` override is for this
  release only (#4175).
- **Recreate agents on the 1.0.5 base image** for the agent-side fixes (see above).
- **An existing install keeps its MCP port and its agents' SSH ports open** until
  `MCP_BIND_ADDRESS` is set and each agent is recreated.
- **Retrieval memory ships switched off.** Turn it on under Settings → General.
- **Direct calls:** stop by voice or by hand shipped; the rest of mid-reply interruption is
  still in progress (ent#1087).
- **Funding an agent with a card** covers enrolling a card and creating a mandate; the
  combined Integrations pane follows (ent#965).
- **Signed agent identity between instances** stays opt-in (`AAUTH_ENABLED`).
- **Pull dispatch is an opt-in pilot** per agent; push dispatch remains the default.
- **No freeze plan or coherence review** was run for this cycle; the payload was tested
  through rc1–rc4.
