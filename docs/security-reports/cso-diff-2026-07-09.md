### [1] LOW — Cross-tenant execution-existence enumeration oracle (Invariant #186)

**File:** `src/backend/routers/internal.py:205-207` · **Status:** VERIFIED (independent refutation subagent → CONFIRMED)

`POST /api/internal/tasks/{execution_id}/result` splits the ownership check into two response codes:
```python
201    execution = db.get_execution(execution_id)
202    if execution is None:
205        raise HTTPException(status_code=404, detail="Execution not found")   # doesn't exist
206    if not heartbeat_service.authorize_heartbeat(key, execution.agent_name):
207        raise HTTPException(status_code=403, detail=_PULL_AUTH_DENIED)        # exists, not yours
```
The `#1083` callback it claims to mirror does the opposite — a **uniform 404** (`agents.py:1045`):
```python
1045    if not execution or execution.agent_name != agent_name:
1047        raise HTTPException(status_code=404, detail="Execution not found")
```
So the pull endpoint reintroduces the exact 404-then-403 differential the self-uniform invariant (#186, `test_186_enumeration_uniformity.py`) forbids.

**Exploit:** any holder of a valid agent-scoped MCP key (compromised pilot / exfiltrated `TRINITY_MCP_API_KEY`) POSTs to `/api/internal/tasks/<id>/result` — **403** ⇒ `<id>` is a real execution owned by another agent, **404** ⇒ it doesn't exist. Reachable against **all** executions (`get_execution` reads the whole `schedule_executions` table) and **even with pull-mode OFF** — the result endpoint's auth is inline, not gated on the `is_pull_pilot_agent` allowlist, and `pull_router` is mounted unconditionally (`main.py:937`). Ships live, not dark.

**Impact: LOW.** Confirmation-only, for ids the attacker already holds via a side channel — execution_ids are 128-bit `secrets.token_urlsafe(16)`, so the space is **not** enumerable. (Invariant #186 targets low-entropy *agent names*; for 128-bit ids the disclosure is minimal — hence LOW, not the usual MEDIUM.)

**Fix (one-liner):** fold both into a uniform 404, mirroring `agents.py:1045`:
```python
execution = db.get_execution(execution_id)
if execution is None or not heartbeat_service.authorize_heartbeat(key, execution.agent_name):
    raise HTTPException(status_code=404, detail="Execution not found")
```

## Positive notes (net security improvement)
- **Least-privilege auth:** the pull seams use the agent's **own scoped MCP key** (dual-auth) instead of injecting the master `INTERNAL_API_SECRET` into pilot containers (the prior design). A compromised pilot can only act on itself and cannot reach the other `/api/internal/*` endpoints (#307/#1159).
- **Terminal write is tightly gated:** `claim_token` (256-bit) + status precondition + ownership — a stale/wrong-token/cross-agent result cannot clobber a terminal row.
- **Result content sanitized** (`sanitize_response` / `sanitize_execution_log`) before persistence.
