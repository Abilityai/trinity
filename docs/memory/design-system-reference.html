Buttons — BaseButton

Four variants, two sizes. One primary action per view. Destructive verbs are named ("Delete agent", never "OK"), and every button states exactly what happens.

12

Data loading — the scanline standard

The app has one data-loading motion (ent#245, concept C): while loading, a glowing beam sweeps the dimmed chart track; when data arrives, one final left→right pass wipes the chart in behind it and headline values flip from the em-dash. First load animates — scheduled background refreshes are invisible (ent#253): stale-while-revalidate, values swap in place, no re-flash, no scroll reset. Loading means "no data yet", never "fetch in flight"; cache hits skip the beam entirely.
