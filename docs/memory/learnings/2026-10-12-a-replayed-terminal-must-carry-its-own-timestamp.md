## 2026-10-12 — pitfall — A writer that stamps `completed_at = now` is correct only while every caller finalizes as the work ends; the first recovery path that replays a terminal later fabricates the duration
**Context**: trinity#3589 (fourth occurrence of the fabricated-duration class after #45, #767, #1804). `update_execution_status` and `complete_activity` both stamped `completed_at` from the clock and measured `duration_ms` to it. Every live writer finalized within seconds of the turn's end, so the stamp was the end — until #2944 added the watchdog claim, which applies the agent's retained terminal ≥ 180 s (claim grace) + up to 300 s (one cleanup cycle) after the agent finished. A 64 s turn was recorded as 5 m 33 s on the execution row AND the dispatch activity, on the same page as a transcript footer that said 1 m 4 s. The claim path HAD the finish time (`retained_at`, parsed for the grace check) and read it only for that; the #1083 result callback has the same shape (retried up to the slot-lease deadline, re-sent by the startup sweep) and the same writer. The #1832/#2434 AST guard stayed green throughout: it checks that `duration_ms` is *measured between two instants*, not that the second instant is the right one.
**Lesson**: (1) When a terminal is produced in one place and applied in another, the producer's timestamp is part of the terminal — put it on the wire contract (`ExecutionResultEnvelope.completed_at`) and thread it through the one mapper both consumers share, so the writer measures to *when the work ended*, not to *when the write happened*; `None` keeps "now" for every in-line caller. (2) The normalization and the bound belong in the WRITER, in one helper both writers call (`terminal_completed_at`: naive → UTC, never in the future, the low end stays the #1832 clamp) — a producer-chosen instant is a trust-boundary input like `execution_time_ms`, and a bound that lives in one caller's helper is the one the next producer forgets. (3) When a recovery path reuses a value it already parses for a *different* decision (here: the grace check), use ONE parser for both reads so they cannot disagree on a format edge, and check the fallback at the point of use: `_retained_age_seconds` returned `+inf` for an unreadable stamp, and the final log line did `int(age)` outside the try — the sweep would have crashed after the CAS already won. (4) A guard that pins the *shape* of a measurement (`duration_ms_between(a, b)`) does not pin its *inputs*; when a new producer of `b` appears, the regression test is the producer-to-row round trip (`completed_at == retained_at`), not another AST rule.
