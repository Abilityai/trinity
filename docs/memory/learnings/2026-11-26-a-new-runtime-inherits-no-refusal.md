## 2026-11-26 — pitfall — A check each runtime must call is not inherited by the next runtime
**Context**: `agent_server/services/turn_scope.require_owner_tier` (ent#926) was called by `gemini_runtime.py` and `codex_runtime.py`. `opencode_runtime.py` was added later without it, so a shared person's turn ran with the agent's whole shell (trinity-enterprise#1384). The ent#926 tests named the two runtimes they knew, so nothing failed. The backend's schedule refusal already treated every non-Claude runtime as refusing, which made the two sides disagree without either being red.
**Lesson**: When a rule is "every runtime except X must do Y at its entry points", the test reads the runtime factory and checks each module it can return, with the exceptions listed by name and reason. A test that enumerates the runtimes it was written for passes on the day a new one is added. Check the call's position too: the gate must be a statement of the entry point's own body, before anything is awaited, and every route into a runtime must pass the turn's id, because a call with none is not asked about.
