## 2026-09-30 — pitfall — `request.url.path` is built from the Host header; security checks read `request.scope["path"]`
**Context**: #3102. Five scope fences in `dependencies.get_current_user` compared `request.url.path`. A Host header carrying `/` or `?` made it name an allowlisted route while the router dispatched a forbidden one. Every existing fence test used `SimpleNamespace(url=SimpleNamespace(path=...))` or TestClient, and neither can express a Host/path desync, so all stayed green.
**Lesson**: Any authorization decision on the request path reads `request.scope["path"]`. A test for a path-based check builds a real `starlette.requests.Request` from an ASGI scope with a crafted `host` header; a fake that stores only the attribute the code reads cannot catch a disagreement between two sources of that attribute. `tests/unit/test_3102_host_header_fences.py` fails on any `.url.path` read under `src/backend`.
