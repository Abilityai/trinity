## 2026-11-22 — pitfall — A measured zero is a value: `x if x else None` turns it into "never measured"
**Context**: #4702, the second site of the #4685 class. `#4699` fixed the monitoring router's own response builder, but `monitoring_service.perform_health_check` built `uptime_percent_24h` and `avg_latency_24h_ms` with `round(x, 1) if x else None`, so an agent down for the whole 24 h window (uptime `0.0`) or a measured 0 ms latency came back as `null` from `POST /api/monitoring/agents/{name}/check`, the MCP check tool and the first-check path of `GET /api/monitoring/agents/{name}` — every consumer reads `null` as "no history".
**Lesson**: For a numeric field where `None` means "not measured", gate on `is not None`, never truthiness. When fixing one builder of a value, grep every other builder of the same field (`round(.*) if .* else None`) in the same change, and test the zero case end to end through the function that returns it — not only the db helper that computes it.
