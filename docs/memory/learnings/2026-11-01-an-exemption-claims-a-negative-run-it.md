## 2026-11-01 — pitfall — An exemption claims a negative, so run each exempted form with the forbidden flag attached
**Context**: trinity-enterprise#1002. The guardrail let `claude mcp` and `claude plugin` through as commands that start no session. That was checked against `--help` output and the usual subcommands, and the tests pinned the regex against that belief. `/review` ran each form against a stub that counts model calls: `claude mcp -p x` reached the model, because `-p` before any `--` skips subcommand parsing. A `-p` after `--` is the MCP server's own argument, and `claude --version -p x` exits first, so a rule written from reasoning alone would have been wrong in both directions.
**Lesson**: a must-pass table only proves what the regex does. When an exemption rests on a fact about an external binary, prove the fact on the pinned binary with a counter on the side effect that matters, and try each exempted word combined with whatever the rule exists to stop. Keep the fact in the list that is re-audited when the binary's pin moves.
