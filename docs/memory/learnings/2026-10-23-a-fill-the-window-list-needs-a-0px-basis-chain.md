## 2026-10-23 — pitfall — A "fill the window" list needs a 0px-basis chain up to the root, and once it scrolls on its own nothing above it may toggle
**Context**: #3451 (Operations lists grew the page to 5,000–21,000 px). The house idiom for a flex-filled scroller is `flex-1 min-h-0` (`AgentDetail.vue::FULLSCREEN_TABS`), which works under an `h-screen overflow-hidden` root — but that root clips, so it cannot give "a short window scrolls the page by the shortfall". Under an auto-height `min-h-dvh` root, Tailwind's `flex-1` is a **0% basis**, and a percentage of an indefinite height resolves as the content's height: the list regrew the page (30,306 px for 300 rows, measured identically in Chromium, Firefox and WebKit). A probe of the CSS alone, before touching the app, settled it; both plan reviewers had reasoned it through and neither ran it. Second half: moving the list into its own scroller removed the page's scroll anchoring for everything ABOVE the list — a bulk-action bar appearing on the first ticked checkbox, a "running now" strip toggling with fleet activity and a stale banner that blinked per poll (its store clears `error` as each read starts) all now moved the list under the reader's pointer, where the page used to absorb them.
**Lesson**: (1) For a list that takes the window's remaining height with a floor, use `min-h-dvh flex flex-col` at the root and `grow basis-0 flex flex-col` on EVERY element down to the scroller (`w-full` on any with `mx-auto` — auto margins suppress the stretch), and put the floor on the scroller (`min-h-[20rem]`); never `flex-1` in that chain, and never a block wrapper. `components/BoundedRegion.vue` packages it. (2) The guards that catch a broken chain are relative and need spare height: the region must reach `main`'s content-box bottom, and grow by exactly what the window grows by at two tall windows — at a window where the list already sits at its floor, a missing link changes nothing measurable (a mutant survived the 1440×900 check and died at 1100→1400). (3) When a list becomes its own scroller, audit everything above it that changes height on its own (polls, sockets, selection) and move it into a fixed-height row; a banner raised by the user's own verb may stay. (4) In e2e, `locator.click()` scrolls its target into view first — an anchoring assertion around a "Load more" click must start where the reader would be (the end of the list), or the test measures Playwright's scroll.
