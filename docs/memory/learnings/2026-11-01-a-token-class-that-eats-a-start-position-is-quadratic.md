## 2026-11-01 — pitfall — In a search regex, a token class that can consume the match's own start characters is quadratic, and a hook that outlives its timeout lets the tool run
**Context**: trinity-enterprise#1002. `gated_bash_deny` starts a match at `;`, `&`, `|` or `(`, then skipped option tokens with `-\S+` and `\d\S*`. `\S` also consumes those start characters, so `env -x;` repeated rescanned the rest of the command from every `;`: 8.4 s at 64 KB, over the hook's 30 s timeout near 128 KB, and this CLI lets the tool run when a hook times out. The time-budget test was green, because its units held spaces and words but no start character. An earlier draft was exponential: `-u NAME` and `VAR=value` could each parse two ways.
**Lesson**: for a rule run with `search` on untrusted text, exclude the start set from every inner token class, and give each token exactly one parse. Build the time-budget corpus from units that contain the start characters, and run it at the largest input a caller can pass. See `2026-10-22-a-sanitiser-inherits-its-callers-input-bound.md` for the input-bound half.
