## 2026-11-01 — pitfall — In a search regex, a token class that can consume the match's own start characters is quadratic, and a hook that outlives its timeout lets the tool run
**Context**: trinity-enterprise#1002. `gated_bash_deny` starts a match at `;`, `&`, `|` or `(`. Option tokens used `\S`, which also consumes those characters, so `env -x;` repeated rescanned the rest of the command from every `;`: 8.4 s at 64 KB. This CLI lets the tool run when a hook times out. The fix bounded the option tokens and the time-budget test went green, then `/review` found the same defect one token over: the assignment value still accepted `(`, so `A=(` repeated took 7.5 s at 64 KB. The corpus had been written by hand from the units the author had already thought of. An earlier draft was exponential: `-u NAME` and `VAR=value` could each parse two ways.
**Lesson**: for a rule run with `search` on untrusted text, exclude the start set from every inner token class, give each token exactly one parse, and cap any scan that can restart at each start position. Then fuzz it instead of listing cases: repeat token pairs and triples at two sizes and read the growth ratio, 2 for linear and 4 for quadratic. Take the tokens from the pattern itself. See `2026-10-22-a-sanitiser-inherits-its-callers-input-bound.md` for the input-bound half.
