## 2026-09-28 — architecture — A credential minter must be at least as strict as the principal class it produces
**Context**: `routers/mcp_keys.py` — `POST /api/mcp/keys` and `POST /api/mcp/keys/ensure-default` now take `Depends(require_interactive)`, and `ensure-default` writes the `key_create` audit row the create route already wrote.
**Lesson**: When an auth rule admits a credential class, the routes that create that class (mint, bind, rotate — convenience paths included) must take a rule at least as strict as every rule the credential will satisfy. In Trinity that means INTERACTIVE (`require_interactive`, JWT only) on every key-creation path; anything weaker makes the admitting rule circular. Audit every creation path, not only the main one, so each credential can be traced to the session that made it.
