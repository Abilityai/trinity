## 2026-11-13 — pitfall — A rating rule added ahead of an existing narrowing silently overrides it
**Context**: abilityai/trinity-enterprise#1225, PR #4546. `turn_tier_service._rate` gained "a continuation is rated as the turn it continues" as its first branch. An answer resume reported into a Workspace chat also carries `source_channel=portal` + `source_channel_client`, which the later `_workspace_person` branch rated `(share, person, None)`. With the link present the portal branch was never reached: a client's answer to an owner turn's ask would have run at owner tier with its reply and files delivered to that client. Every new test passed; an independent review caught it.
**Lesson**: Before putting a new branch first in a tier/attribution function, list every field on the row that an existing branch narrows on (portal stamp, channel client, schedule creator) and decide, per producer, which wins. A row a producer stamps with an audience must not also be stamped with an authority link that out-ranks that audience. Test the combination at the producer, not only each rule alone.
