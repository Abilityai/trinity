## 2026-11-03 — pitfall — An empty submodule directory makes `enterprise` importable in a checkout and absent in the image
**Context**: #4175, `db/sqlite_to_postgres.py`. `importlib.util.find_spec("enterprise.backend")` passed every unit test, including an end-to-end copy against real PostgreSQL, because `src/backend/enterprise/` exists as an empty directory in any worktree and Python treats it as a namespace package. The image has no such directory, so `find_spec` raised `ModuleNotFoundError` for the missing parent and the command crashed on every OSS install. Only a run inside the built image showed it.
**Lesson**: Optional-package detection must handle the parent being absent, and a test has to use a name whose parent really is missing. A command that runs inside an image and has its own entry point gets one real run in that image before it counts as tested.
